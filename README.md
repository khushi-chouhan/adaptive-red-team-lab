# Adaptive Red-Team Lab for AI Agents

A controlled Linux-based cybersecurity research project exploring adaptive red-team testing of AI agents.

## Research Question

Can feedback from previous security tests be used to make automated red-team testing of AI agents more effective?

## Research Direction

Automated and Adaptive Red Teaming of AI-Enabled Systems

## Project Goal

Build a local prototype that follows this process:

AI Agent -> Security Test -> Result -> Feedback -> Adapted Test -> Security Report
